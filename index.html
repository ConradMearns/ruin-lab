FIELD NOTES / 001

Nothing stays standing forever.

Ruin Lab is a small experiment in how time changes architecture. Pick a structure, tune the elements, and run a possible history.

01

Set the conditionsFive independent passes run each step: exposure → rain (optional) → collapse → sediment → overgrowth.

02

Travel through timeDrag the timeline or press play. Orbit with your mouse, pan with a right-drag, and scroll to get closer.

03

Take the history with youExport a timelapse with the original structure and incremental voxel patches. Export the current structure for a standalone snapshot. Both can be imported here.

An open, simple format

{ "version": 1, "size": [12, 8, 10],
  "materials": {
    "0": { "name": "air" },
    "1": { "name": "stone", "color": "#8a8a85",
           "durability": 1, "decays_to": "0" }
  },
  "voxels": [[0, 0, 0, 1]] }

Y is up. Material 0 is air. Each timelapse frame has t (years) and set ([x, y, z, material] updates). A fixed seed gives repeatable results. These are artistic approximations, not engineering forecasts. Sediment needs a ground material; generated plants are included in exports.
